
## What is JavaScript and what are its main features?

JavaScript is a high-level programming language used to make web applications interactive and dynamic. It is used for frontend development and backend development with Node.js.

### Main Features of JavaScript

1. **Dynamic Typing:** Variables can store different types of values.
2. **Lightweight:** It is easy to use and efficient.
3. **Event-Driven:** It responds to user actions like clicks.
4. **Asynchronous:** It handles tasks using Promises and async/await.
5. **Object-Based:** It works with objects and supports prototype-based inheritance.
6. **Cross-Platform:** It runs in web browsers and on servers using Node.js.

### Short Interview Answer

JavaScript is a high-level programming language used to make web applications interactive and dynamic. Its main features include dynamic typing, event-driven programming, asynchronous operations, and cross-platform support. It is used for frontend development as well as backend development with Node.js.
