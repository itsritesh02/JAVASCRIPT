
# Difference Between `==` and `===` in JavaScript

## Interview Question

What is the difference between `==` and `===` in JavaScript?

## Interview Answer

In JavaScript, `==` compares two values after type conversion, while `===` strictly compares both value and data type without type conversion.

For example:

```javascript
console.log(5 == "5");  // true
console.log(5 === "5"); // false
```

We prefer `===` because it strictly checks both value and data type, giving more accurate and predictable results.
