
# What is a Function in JavaScript?

## Interview Question

What is a function in JavaScript?

## Interview Answer

A function is a block of code that performs a specific task. We can reuse a function whenever we need it by calling it.

## Example

```javascript
function greet() {
  console.log("Hello World");
}

greet(); // Hello World
```

## Explanation

- `function` is used to create a function.
- `greet` is the function name.
- `console.log()` prints the message.
- `greet()` calls the function.

## Short Interview Answer

A function is a reusable block of code that performs a specific task. We can call it whenever we need to execute that code.
